Join as a voting validator

Run a node on your own computer and join the voting rotation with your GitHub identity. No administrator approval or API token is needed.

1. Start your node

Install and start Docker, then run these commands in a terminal. Replace YOUR_GITHUB_USERNAME with your lowercase personal GitHub username.

curl -fsSLo install-reviewer.sh https://trustseco1.science.uu.nl/reviewer/install-reviewer.sh
sh install-reviewer.sh YOUR_GITHUB_USERNAME
docker logs -f trustseco-reviewer

The installer downloads an approximately 560 MB image and checks its SHA-256 checksum. It uses an AMD64 Linux container; Docker Desktop can run it on an Apple Silicon Mac using emulation.

2. Link your public signing key

Your node prints a public key beginning with ssh-ed25519. Add it in GitHub’s SSH key settings, selecting Signing Key. Your account must be at least 180 days old. Private keys stay in your local Docker volume.

3. Let it synchronize

Your node downloads and validates the ledger, then requests admission automatically. Its logs report when it is waiting for a turn or actively voting. Four validators vote at a time, with equal weight. A normal rotation changes one seat every 16 blocks—about four minutes.

Stop and return

docker stop trustseco-reviewer
docker start trustseco-reviewer

A normal stop waits for your departure to finalize. Keep the trustseco-reviewer volume and never run two copies of the same signing identity. Abrupt disconnection may leave a validator scheduled; the four-seat committee tolerates one unavailable voter.

This research demo includes six clearly labelled operator-controlled test contributors. Their agreement exercises the protocol and does not establish independent verification. GitHub admission verifies account age and key ownership, not one person per account. Data collection and its optional API credentials are separate from voting.
